Имена
Напомним, что переменным, классам и методам нужно давать точные, «говорящие» имена

int sumOfAnglesOfTriangle = firstAngle + secondAngle + thirdAngle; ВМЕСТО A + B + C

Имена переменных
Названия переменных пишут в lowerCamelCase. Они должны чётко отражать содержимое этих переменных
 из одного символа, можно использовать только в общепринятых случаях (например, i и j для счетчиков в циклах). 

int amountOfActors;
String currentCity;
for (int counter = 0; counter < 10; counter++)
for (int i = 0; i < 10; i++) // Тоже допустимо.

// понятные имена переменных написаны с соблюдением lowerCamelCase

Имена классов
В названиях классов используют только имена существительные или словосочетания с ними, написанные в UpperCamelCase.

class Apple
class FinancialCalculator
class HashMap

/* В названиях классов используются UpperCamelCase 
   и имена существительные, написанные по-английски. */

Имена методов
Названия методов начинают с глаголов. Все слова нужно писать в lowerCamelCase. Тип метода указывать в названии не нужно.

setWeight();
makeChair();
executeAction();
driveToParking();

// названия методов написаны в lowerCamelCase и начинаются с глаголов
